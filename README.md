# IELTS practice

[Open the Academic IELTS practice site](https://stormaref.github.io/ielts/).

Cambridge IELTS 18, Test 1 includes all four skills. Mark a Reading passage or Listening part to see a score, or save a Writing or Speaking response for review. Use **Download test results** to take your answers and scores with you. Speaking recordings have their own download button.

The Pages tracker is read-only. Online attempts stay in the browser. To manage scores for Cambridge 18–21, open the local project’s `index.html` and select **Import results**. The local study library lives in `Cambridge Practice Tests/`, with a `Source text/` folder in each test directory.
